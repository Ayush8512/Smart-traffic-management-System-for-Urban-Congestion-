# Smart-traffic-management-System-for-Urban-Congestion-
This prototype uses TensorFlow.js for real-time traffic analysis to dynamically control signals, reducing congestion. It features an automated ANPR system to penalize red-light violators with E-Challans, and a reward system to encourage safe driving habits. The entire system runs client-side, directly in the browser.
